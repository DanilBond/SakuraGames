# Zoo World

Небольшая симуляция со змеями и лягушками. Змеи ползают, лягушки прыгают. При столкновении змея съедает лягушку, а из двух змей выживает та, которая появилась раньше.

Справа сверху отображаются счётчики погибших. После поедания под хищником появляется анимированная надпись `Tasty!`.

## Запуск

Открой проект в **Unity 6000.3.14f1**, загрузи сцену `Assets/Scenes/Main.unity` и нажми Play. Симуляция работает сама, управления нет. Для загрузки VContainer через Package Manager нужен установленный Git.

## Код и настройки

Основной код лежит в `Assets/_Project/Scripts`:

- `Core` - состояние животных, правила поедания и статистика, без зависимостей от Unity.
- `Runtime` - спавн, пул объектов, движение и UI. Зависимости собираются через VContainer в `GameLifetimeScope`. Для текста используются TextMeshPro и DOTween.
- `Editor` - окно добавления животного: **Zoo World → Add Animal**.

Параметры животных, движения и спавна хранятся в ScriptableObject в `Assets/_Project/Data`.

Тесты находятся в `Assets/_Project/Tests`. Запуск: **Window → General → Test Runner → EditMode**.
